01

项目概览Overview

国内咖啡文化尚处萌芽阶段，而咖啡消费需求正以每年约 20% 的速度增长， 一个潜力巨大的市场正在“新丝路”上崭露头角。但当时国内缺少专门的平台， 把一带一路沿线国家的咖啡产地与中国消费者直接对接起来。

咖cool 想同时解决“看懂”和“买到”：先用内容让人对咖啡产生兴趣，再自然地走到购买。 所以信息架构不是常见的“首页 + 商品列表”，而是四个并列入口—— 咖趣做文化科普，咖屋放商品与器具， 咖话承载社区与话题，个人中心处理账户与订单。

项目最终产出两条线：一条是可以真实点开、跑得起来的网站； 另一条是按完整交互设计流程走完的APP 原型。

两条交付线

  • 网站（已开源）：8 个页面，纯手写 HTML / CSS / 原生 JavaScript， 注册登录基于 ASP.NET + SQL Server
  • APP 原型：项目背景 → 竞品分析 → 用户研究 → 信息架构 → 设计规范 → 界面展示，共 6 个阶段

我负责的部分

  • 品牌命名、Logo 设计与动态标识（AE 动画）
  • 整站信息架构与页面视觉设计
  • 网站全部前端实现与交互逻辑
  • 注册登录后端与数据库
  • APP 端用户研究、信息架构、设计规范与界面设计
02

品牌与动态标识Brand

品牌名“咖cool”取“咖啡”与 cool 的双关，中英混排既有亲和力， 又留出年轻化的表达空间。中文用手写风格字体，配花体英文 slogan “Add cool to life”。

主色取自烘焙后的咖啡豆——#56432E；点睛色取自杯口奶泡的光泽—— #EDDE29。这套配色在网站与 APP 两条线上保持一致， Logo 的黄色咖啡杯也贯穿始终。

Logo 另做了一版动态标识，用于 APP 启动页与网站加载页： 文字逐笔浮现、杯中热气升腾，收尾停在完整标志上。站内 加载中....html 就是它的过场页面。

网站 · 技术实现Build

01

样式分层

CSS 按职责拆成 reset.css（重置）、public.css（通用）、 nav.css（导航）与各页面专用文件，公共部分只写一次，改一处全站生效。

02

交互实现

用原生 JavaScript 写轮播的自动播放与左右切换、分类侧栏的展开收起、 购物车的数量增减与价格联动，不依赖任何第三方库。

03

图标与字体

自建 iconfont.ttf 承载首页一级导航的五个图标， 保证不同分辨率下都清晰，也避免多张小图带来的额外请求。

04

账户功能与数据库

用 Visual Studio 建立 ASP.NET 项目，编写 register.aspx 与 login.aspx 的后台逻辑，连接 SQL Server 完成用户表的写入与校验。

05

整理开源

把项目整理后推到 GitHub：用 .gitignore 排除 ASP.NET 构建产物 （bin/、obj/、packages/）与数据库文件， 仓库里只留源码、样式、脚本与素材。
